# Data

This project does **not** commit any real Windows event logs.

- Real telemetry lives in a Windows Security `.evtx` file exported from a Domain Controller
  (e.g. `wevtutil epl Security dc_security.evtx`). These are **never** committed — they can
  contain account names, IPs, and other sensitive information, and are covered by `.gitignore`.
- To try the tool without a real log, use the committed synthetic dataset:
  `sample_data/synthetic_events.json` (generated by `sample_data/generate_synthetic.py`,
  containing only fabricated accounts/IPs).

## Expected real-input schema

`--evtx` expects a standard Windows Security log. The parser maps EventData fields for:

| Event ID | Meaning |
|----------|---------|
| 4624 | Successful logon |
| 4625 | Failed logon |
| 4672 | Special privileges assigned (privileged logon) |

Fields extracted: EventID, timestamp, target/subject username, domain, source IP, logon type,
authentication package.
